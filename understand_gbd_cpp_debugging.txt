    GDB ek debugging tool hai jo C/C++ programs me bugs dhoondhne ke liye use hota hai.
    GDB se kya kar sakte hain?
        Program ko line by line execute karna.
        Variables ki value dekhna.
        Crash (Segmentation Fault) ka exact reason pata lagana.
        Function call stack dekhna.
        Breakpoint laga kar execution rokna.
